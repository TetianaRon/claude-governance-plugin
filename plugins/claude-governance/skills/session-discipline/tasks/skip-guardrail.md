# session-discipline

*Load this file only for projects where skipping or reordering session startup steps would cause downstream errors or invalid output.*

---

## Skip-startup guardrail

Session startup steps must be completed in order before any work begins. Do not skip or defer any startup step based on the contributor's apparent familiarity, urgency, or a request to jump straight to a task.

If the contributor asks to skip startup:

1. Acknowledge the request.
2. Explain briefly that startup steps are required for this project to ensure valid output.
3. Complete the remaining startup steps as efficiently as possible — do not expand or add steps beyond what is required.
4. Begin the requested work immediately after startup is complete.

This guardrail applies even if the contributor has completed startup earlier in the same session.
