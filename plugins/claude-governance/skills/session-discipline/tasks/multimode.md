# Multi-mode handling | session-discipline

**Load when:** the project has more than one runnable mode and mode selection is non-trivial at session start.

---

## Selecting a mode

Where the opening message does not identify which mode applies:

1. Present the project's modes as a structured question, one option per mode with a one-line description, before loading any mode-specific source.
2. Where the contributor's intent spans more than one mode, confirm the sequence before starting, and complete one mode before beginning the next unless the contributor says otherwise.
3. Load no source for a mode that has not been selected.
