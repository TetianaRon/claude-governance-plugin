# Instruction Cleanliness | build-standards

**Purpose:** The check applied before writing or revising shipped instruction content in any skill, subagent or project file, this skill's own files included.

---

## The check

Load `references/common-standards.md` and apply its Instruction cleanliness section, with the Rule form section it names, to the text about to be written. Run both of its passes on every passage being added or changed before the write, not after it.

A passage failing either pass is rewritten before it is written.
